# MOSFET 구조와 작동 원리, 처음부터 차분히

작성일: 2026-10-11 · NMOS 기준 (PMOS는 도핑 종류와 전압 부호만 반대)
순서: 구조 → 기초 개념(공핍층) → 작동 원리 → 수식 → 그래프 → trade-off → 메모리 연결 → 면접 한 문장

---

## 1. 구조: 무엇으로 이루어졌나

```
        Source        Gate          Drain
          |        ┌────────┐         |
      ┌───┴───┐    │ 금속/폴리 │    ┌───┴───┐
      │  n+   │    ├────────┤    │  n+   │
      │       │    │ 산화막(SiO2/High-k) │       │
      │       └────┴────────┴────┘       │
      │            p형 기판 (Body)         │
      └──────────────────────────────────┘
                     Body 단자
```

| 부분 | 재료·도핑 | 역할 |
|---|---|---|
| Gate | 폴리실리콘 또는 금속 | 전압으로 채널을 만드는 **제어 단자** |
| Gate 산화막 | SiO₂, 최근엔 High-k | 게이트를 기판과 **절연**. 얇을수록 제어력이 큼 |
| Source / Drain | n+ (약 1e20/cm³) | 전자의 **공급원 / 배출구**, 금속과 오믹 접촉 |
| Body(기판) | p형 (약 1e15~1e18) | Vth와 이동도를 정하는 영역, 평소엔 전류가 안 흐르는 쪽 |
| Channel | 게이트 아래 표면 | 평소엔 없고, 게이트 전압이 **만드는** 전도 통로 |
| L, W | 채널 길이·폭 | 전류 ∝ W/L |

핵심 특징 두 가지
1. **게이트가 절연**되어 있어 DC 입력 전류가 거의 0이다. (BJT와 가장 큰 차이)
2. 채널은 평소엔 없다(**enhancement mode**). 게이트 전압이 만들어 줘야 켜진다.

## 2. 기초 개념: pn 접합과 공핍층 (MOSFET 이해의 토대)

### 2-1. 공핍층이 생기는 과정
1. n쪽엔 전자가, p쪽엔 정공이 많다. 이 **농도 차이** 때문에 전자는 p로, 정공은 n으로 **확산**한다.
2. 건너간 캐리어는 상대편 캐리어와 재결합해 사라진다.
3. 캐리어가 떠난 자리에는 **움직일 수 없는 도펀트 이온**이 남는다. n쪽은 도너(+), p쪽은 억셉터(−).
4. 이 +/− 이온 사이에 n→p 방향 **전기장**이 생겨 캐리어를 되돌려 보낸다(drift).
5. 확산과 drift가 같아지면 **평형**(순 전류 0). 자유 캐리어가 없고 이온만 남은 구간이 **공핍층**.

### 2-2. 폭을 정하는 규칙
- 양쪽 전하량이 같아야 하므로 N_A·x_p = N_D·x_n → **옅은 쪽으로 넓게** 퍼진다.
- W ∝ √(1/N) → **도핑이 진할수록 얇다.**
- 순방향 바이어스는 공핍층을 좁히고(장벽↓), 역방향은 넓힌다(장벽↑).

### 2-3. 이게 MOSFET에서 쓰이는 곳
- S/D(n+)–Body(p) 접합: 게이트가 꺼져 있을 때 전류를 **막는** 다이오드
- 게이트 아래 표면: 반전층이 생기기 **전에** 먼저 생기는 공핍층
- 드레인 쪽 공핍층: 채널 길이가 짧을 때 소스까지 뻗으면 SCE, Punch-through

## 3. 작동 원리: 게이트 전압에 따라 표면에서 일어나는 일

게이트–산화막–Body는 **MOS 커패시터**다. 게이트에 걸린 전압(V_GS)에 따라 기판 표면이 세 단계로 바뀐다.

| 단계 | 조건 | 표면에서 일어나는 일 | 전류 |
|---|---|---|---|
| ① 축적/평탄 | V_GS ≤ 0 | 정공이 표면으로 끌려옴(p형 그대로) | 없음 |
| ② 공핍 | 0 < V_GS < Vth | 게이트의 +전압이 정공을 **밀어내서** −억셉터 이온 층(공핍층)이 드러남. 전자는 아직 없음 | 없음 (누설만) |
| ③ 반전 | V_GS ≥ Vth | 공핍층이 최대 폭에 이른 뒤, S/D에서 온 **전자가 표면에 모여** n형처럼 변함 = **채널** | V_DS를 걸면 흐름 |

핵심: 게이트가 전자를 "만드는" 게 아니라, **정공을 밀어내서 공핍시킨 뒤, 소스·드레인에 이미 있는 전자를 표면으로 끌어오는** 것이다.

### Vth가 왜 그 값인가
게이트 전압은 두 일을 해야 채널이 생긴다.
1. 공핍 전하 Q_d(−이온)를 **먼저 상쇄** → 산화막 양단 전압 Q_d/C_ox
2. 표면의 전자 농도를 body의 정공 농도(N_A)와 같게 만들기 위해 밴드를 **2φ_F만큼 휘기** (φ_F = (kT/q)·ln(N_A/n_i))

**Vth = V_FB + 2φ_F + Q_d/C_ox** (V_FB는 일함수 차이 등을 보정하는 항)

그래서 body 도핑 N_A가 크면 Q_d ∝ √N_A 와 φ_F가 모두 커져 **Vth가 올라간다.** 공정에서 Vt implant로 Vth를 맞추는 이유다.

### 채널이 만들어진 뒤, 전류는 어떻게 흐르나
V_DS를 걸면 전자가 소스에서 드레인으로 **drift**한다(전계에 끌려감). 전류 방향은 드레인→소스. **전자만** 전도에 참여하므로 unipolar(다수캐리어 소자)다.

## 4. 동작 영역과 수식

V_ov = V_GS − Vth (과구동 전압)

| 영역 | 조건 | 채널 모양 | 전류 | 용도 |
|---|---|---|---|---|
| Cutoff | V_GS < Vth | 없음 | ≈0 (subthreshold 누설) | OFF 스위치 |
| Triode(Linear) | V_DS < V_ov | 소스~드레인 연결, 드레인 쪽이 좁아짐 | I_D ≈ μC_ox(W/L)[V_ov·V_DS − V_DS²/2] | **저항형 스위치**, pass gate |
| Saturation | V_DS ≥ V_ov | 드레인 끝에서 **pinch-off** | I_D ≈ ½μC_ox(W/L)V_ov²(1+λV_DS) | **전류원, 증폭기** |

### 왜 포화가 생기나 (pinch-off)
- 채널 전압은 소스에서 드레인으로 갈수록 올라가서, 드레인 쪽에서는 (게이트 − 채널) 전압차가 작아진다.
- V_DS = V_ov가 되면 드레인 끝에서 이 전압차가 Vth 이하가 되어 반전층이 사라진다(pinch-off).
- 그 뒤로는 V_DS를 더 올려도 pinch-off 지점의 전압이 V_ov로 고정되어, 전류가 V_DS와 거의 무관해진다. 끊어진 구간은 강한 전계의 공핍영역이라 전자는 **그대로 끌려가서** 드레인으로 간다.
- λ항은 pinch-off 지점이 소스 쪽으로 밀려 실효 채널이 짧아지는 **채널 길이 변조(CLM)**.

### 소신호 파라미터
- g_m = ∂I_D/∂V_GS = 2I_D/V_ov (입력 전압 → 전류 변환 능력)
- r_o = 1/(λI_D) (유한한 출력저항)
- 고유 이득 = g_m·r_o (트랜지스터 하나가 낼 수 있는 최대 이득)

### Subthreshold (V_GS < Vth)
I_D ∝ exp(V_GS / (n·V_T)) — Vth 아래에서도 **지수적**으로 흐른다. 기울기 S = n·V_T·ln10 ≈ 60mV/dec 이상. 이것이 대기 전력과 DRAM retention의 핵심 문제다.

## 5. 그래프로 정리

**I_D–V_DS (V_GS를 바꿔 가며)**
```
 I_D
  |        _______________ V_GS3
  |      _/ ______________ V_GS2
  |    _/ _/ _____________ V_GS1
  |  _/ _/ _/
  | / / /  ← Triode | Saturation →
  +-------------------------- V_DS
        (경계: V_DS = V_GS − Vth)
```
- 왼쪽(triode)은 원점을 지나는 직선 → 저항
- 오른쪽(saturation)은 평평 → 전류원

**I_D–V_GS (전달 특성)**
- V_GS < Vth: 지수적으로 작은 전류 (log 스케일에서 직선)
- V_GS > Vth: V_ov²에 비례해서 증가 (포화)

## 6. 설계 요소와 trade-off

| 요소 | 얻는 것 | 대가 |
|---|---|---|
| W/L 증가 | 전류↑, 속도↑ | 면적·게이트 용량·누설↑ |
| Tox 감소(High-k) | 게이트 제어력↑, I_ON↑ | 게이트 터널링 누설↑ |
| Vth 낮춤 | I_ON↑, 속도↑ | I_OFF(누설) 지수적으로↑ |
| Body 도핑↑ | SCE·Punch-through↓ | Vth↑, 이동도↓, 접합 누설↑ |
| S/D n+ | 오믹 접촉, 저저항 | 드레인 끝 전계 집중(Hot Carrier, GIDL) → **LDD** |
| Gate–S/D overlap | 채널과 S/D가 끊김 없이 연결 | C_gd(Miller)↑, GIDL↑ → **최소화** |
| 채널 단축(scaling) | 속도·집적도↑ | SCE: DIBL, Vth roll-off → FinFET, GAA로 대응 |

## 7. 메모리와의 연결

- **DRAM 셀 Tr**: 스위치 + 커패시터(1T1C). 핵심은 **OFF 누설 최소화**(retention). 그래서 Vth를 높게, 채널을 길게(Recess·Buried 게이트), 접합 전계를 완화(GIDL 억제)하고, 필요하면 음의 body bias로 Vth를 확보한다.
- **DRAM Peri Tr**: 속도가 우선이라 얇은 산화막, 낮은 Vth, LDD 구조를 쓴다.
- **NAND 셀**: MOSFET에 floating gate/charge trap을 얹어 **Vth를 전하량으로 바꿔 저장**하는 소자다. 읽을 때는 Vth 차이를 감지한다.
- **로직(CMOS)**: NMOS와 PMOS를 짝지어 정적 전력을 ≈0으로 만든 것이 오늘날 집적의 기반이다.

---

## 8. 면접 한 문장

> "MOSFET은 절연된 게이트 전압이 Vth를 넘으면 기판 표면에 반전층 채널이 형성되어 소스에서 드레인으로 다수캐리어가 drift하는 전압 제어 소자이며, V_DS에 따라 저항형(triode)과 전류원형(saturation)으로 동작하고, 메모리에서는 누설 최소화(DRAM)와 Vth 기반 저장(NAND)에 활용됩니다."

## 한눈에 보는 인과 사슬

게이트 +전압 → 정공 밀려남(공핍층) → Vth 도달 → 표면에 전자 모임(반전층 = 채널) → V_DS로 drift → 전류 I_D → V_DS가 V_ov를 넘으면 pinch-off로 포화
