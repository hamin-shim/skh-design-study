# A!SK 3분 답변: MOSFET의 구조·원리, BJT와 비교

작성일: 2026-10-11 · 문항은행 Q31(동작 영역), Q11(SCE), 밴드갭(BJT VBE) 항목과 같은 표현을 씀
목표 시간: **약 2분 30초** (준비 1분 동안 아래 "뼈대 4줄"만 떠올리기)

---

## 준비 1분 동안 떠올릴 뼈대

1. **결론 먼저**: MOSFET은 전압으로 제어하는 다수캐리어 소자, BJT는 전류로 제어하는 소수캐리어 소자
2. **MOSFET**: 구조(G/산화막/Body, S·D) → 원리(반전층, Vth) → 식(Triode·Saturation)
3. **BJT**: 구조(E/B/C) → 원리(BE 순방향 주입, 얇은 Base 확산, BC 역방향 수집) → IC = IS·e^(VBE/VT)
4. **비교 4가지**: 입력 전류 / gm / 집적·정적전력 / 온도 특성 → **메모리 연결**: Cell·Logic은 MOSFET, 기준전압(Bandgap)은 BJT

---

## 답변 스크립트 (말하는 그대로)

**[도입, ~10초]**
> 결론부터 말씀드리면, MOSFET은 게이트 **전압**으로 채널을 만들어 전류를 제어하는 **다수캐리어** 소자이고, BJT는 베이스 **전류**로 컬렉터 전류를 제어하는 **소수캐리어** 소자입니다. 구조와 원리, 그리고 차이점 순서로 설명드리겠습니다.

**[MOSFET 구조, ~20초]**
> NMOS 기준으로, p형 기판 위에 얇은 게이트 산화막과 게이트 전극이 있고, 양옆에 n+ 소스와 드레인이 있습니다. 게이트, 소스, 드레인, 바디의 4단자 소자이고, 게이트가 산화막으로 **절연**되어 있어서 DC 입력 전류가 거의 흐르지 않는다는 것이 구조적으로 가장 중요한 특징입니다.

**[MOSFET 원리, ~40초]**
> 게이트에 양의 전압을 걸면 산화막을 사이에 둔 커패시터처럼 동작해서, 기판 표면의 정공이 밀려나 공핍층이 생기고, 문턱전압 Vth를 넘으면 표면에 전자가 모인 **반전층**, 즉 채널이 형성됩니다. 이 채널이 소스와 드레인을 이어 주고, VDS에 의해 전자가 **drift**로 흐릅니다.
> VDS가 작을 때는 **Triode** 영역으로, 전류가 VDS에 비례해 **저항처럼** 동작하고, 디지털 스위치가 이 영역을 씁니다. VDS가 VGS−Vth보다 커지면 드레인 쪽 채널이 **Pinch-off** 되어 전류가 ½μCox(W/L)(VGS−Vth)² 로 VDS와 거의 무관해지는 **Saturation** 영역이 되고, 아날로그 증폭기와 전류원이 이 영역을 씁니다. Vth 아래에서도 Subthreshold 누설이 지수적으로 흐르는데, 이것이 메모리에서는 리텐션과 대기 전력의 핵심 이슈입니다.

**[BJT 구조·원리, ~25초]**
> BJT는 NPN 기준으로 이미터, 베이스, 컬렉터가 적층된 구조입니다. 베이스-이미터를 **순방향**, 베이스-컬렉터를 **역방향**으로 걸면, 이미터에서 얇은 베이스로 전자가 주입되고, 베이스에서는 **소수캐리어**인 이 전자가 **확산**으로 건너가 컬렉터의 강한 전계에 수집됩니다. 그래서 컬렉터 전류는 IC = IS·exp(VBE/VT)로 VBE에 **지수적**으로 변하고, 베이스에는 IC/β 만큼의 전류가 계속 필요합니다.

**[차이점 비교, ~45초]**
> 차이는 네 가지로 정리하겠습니다.
> 첫째, **입력 특성**입니다. MOSFET은 게이트가 절연되어 입력 임피던스가 매우 높지만, BJT는 베이스 전류가 필요해 구동 전력이 듭니다.
> 둘째, **gm**입니다. BJT는 gm = IC/VT로, 같은 전류에서 MOSFET의 gm = 2ID/Vov보다 수 배 크기 때문에 고이득·고속 아날로그와 저잡음에 유리합니다.
> 셋째, **집적도와 전력**입니다. MOSFET은 평면 구조라 미세화가 쉽고, NMOS와 PMOS를 묶은 CMOS는 정적 상태에서 전류가 거의 흐르지 않아 수십억 개를 집적하는 디지털과 메모리에 적합합니다. BJT는 미세화가 어렵고 베이스 전류 때문에 정적 전력이 있습니다.
> 넷째, **온도 특성**입니다. BJT는 온도가 오르면 전류가 늘어 열폭주 위험이 있지만, MOSFET은 높은 VGS에서 이동도 감소로 전류가 줄어 상대적으로 안정적이고 병렬 연결이 쉽습니다.

**[메모리 연결 + 마무리, ~20초]**
> 그래서 DRAM 셀 트랜지스터, NAND 셀, 주변 로직은 모두 MOSFET이고, 특히 DRAM 셀 Tr은 스위치로서 **누설을 최소화**하는 것이 핵심입니다. 반면 BJT는 VBE의 온도 특성이 예측 가능해서, CMOS 공정의 기생 PNP로 **Bandgap Reference**를 만들어 VPP 같은 내부 전원의 기준전압과 온도 센서에 씁니다. 즉 **집적과 저전력은 MOSFET, 정밀한 기준은 BJT**로 역할을 나눠 쓴다고 이해하고 있습니다.

## 한눈 비교표 (암기용)

| 항목 | MOSFET | BJT |
|---|---|---|
| 제어 | 게이트 **전압** (절연, I_G ≈ 0) | 베이스 **전류** (I_B = I_C/β) |
| 캐리어·전도 | 다수캐리어, **drift** (unipolar) | 소수캐리어, **diffusion** (bipolar) |
| I–V | Sat: ½μCox(W/L)Vov² (제곱) | IC = IS·e^(VBE/VT) (지수) |
| gm | 2ID/Vov | IC/VT (같은 전류에서 더 큼) |
| 입력 임피던스 | 매우 높음 | 낮음 (rπ = β/gm) |
| 집적·정적전력 | 미세화 쉬움, CMOS 정적전력 ≈ 0 | 미세화 어려움, 정적전력 있음 |
| 온도 | 고 VGS에서 전류 ↓ (자기제한) | 전류 ↑ → 열폭주 위험 |
| 메모리에서 | Cell Tr, 로직, 전원 스위치 | Bandgap Reference, 온도센서 |

**암기 vs 이해**: 식과 표는 암기, "왜 메모리는 MOSFET인가(절연 게이트 → 정적전력 0 → 집적)"는 이해해서 말로 풀 것.

## 예상 꼬리질문 (심층 면접용, 한 줄 답)

- **Pinch-off 후에도 전류가 왜 흐르나?** → Pinch-off 지점에서 드레인까지는 강한 전계가 있는 공핍영역이라 전자가 끌려가 흐름. 실효 채널이 짧아지는 CLM 때문에 λVDS만큼 약간 증가.
- **BJT gm이 왜 더 큰가?** → 지수 특성이라 VT(26mV)라는 작은 전압 단위로 전류가 변함. MOSFET은 Vov(보통 100~200mV)가 그 역할이라 gm/I가 작음. MOSFET도 약반전에서는 지수라 gm/ID가 BJT에 근접.
- **CMOS 안의 기생 BJT가 문제가 되는 경우?** → **Latch-up**: 기생 PNP·NPN이 PNPN 사이리스터를 이뤄 VDD–GND 단락. Guard ring, Well tap 간격으로 방지.
- **Bandgap 원리?** → VBE는 CTAT(약 −2mV/°C), ΔVBE = VT·ln(n)은 PTAT → 비율 맞춰 더하면 온도계수 0, 약 1.2V.
- **BiCMOS를 왜 메모리에서 안 쓰나?** → 공정 단계·비용 증가 대비, 저전압 CMOS로 충분하고 BJT는 기생 소자로 해결 가능.
