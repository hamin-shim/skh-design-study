## 0. 우선순위 (사용자 결정 2026-10-09)

1. **지금 ~ 면접 대상·일정 공지 전: 회로설계 전공 + AI PT만 한다.**

이유: 전공 기초는 A!SK 전공 문항, PT의 원인 분석, 심층 꼬리질문에 모두 쓰이고 쌓는 데 시간이 걸린다. 경험 정리는 이미 아는 내용을 다듬는 일이라 짧은 기간에 몰아서 할 수 있다.

## 1. 1단계: 전공 + AI PT (공지 전, 약 4주)

비중: 전공 70% / AI PT 30%

| 주차 | 전공 범위 (문항은행 번호) | AI PT |
|---|---|---|
| 1주 (10/9–10/15) | 메모리 제품 Q1–Q9 + **Q41**, 디지털 핵심 Q17 Setup/Hold, Q20 RTL→GDSII, Q25 Pipeline | PT #1 합성 후 Setup Violation |
| 2주 (10/16–10/22) | 디지털·검증 나머지 Q18–Q19, Q21–Q24, Q26 + CMOS·Peri Q10–Q16 | PT #2 MBIST 특정 Address Fail, PT #3 Pipeline 후 전력·면적 증가 |
| 3주 (10/23–10/29) | **아날로그 Q31–Q40** (디지털만 준비했다 당황했다는 후기 영역) | PT #4 저전력 모드 Register 값 손실, PT #5 Post-sim 지연 증가 |
| 4주 (10/30–11/5) | 시나리오 Q42–Q47 + 산업 Q27–Q29, 1회독 뒤 무작위 섞기 | PT #6 AI 생성 RTL Coverage 부족, PT #7 Clock Gating Glitch |

### 전공 공부 방식
- 한 문항: 읽기 → 키워드 5개 → 2분 말하기(녹음) → 막힌 부분만 다시
- 골격: 정의 → 원리(왜) → 한계·Trade-off → 설계자 대응 → (선택) 하이닉스 제품 연결
- 완료 기준: 자가 채점 5점 중 4점 이상 (문항은행 9장 기준)
- 막힌 개념은 Claude에게 물어 짧은 카드로 정리

### AI PT 연습 방식 (실제 시간·도구는 공지 후 조정)
- 5분: AI 없이 현상·목표·제약·모르는 정보 메모
- 15분: AI와 원인 가설·필요 데이터·대안 비교, 채택·제외 근거 기록
- 10분: 한 장 정리 (관찰 / 가설 / 검증 방법 / 대안·Trade-off / 결론과 남은 확인)
- 3분 발표 + 7분 꼬리질문 (Claude가 면접관 역할)
- 매회 AI의 틀린 전제나 누락을 하나 이상 찾는다

### 평일 루틴 (60–90분)
| 시간 | 할 일 |
|---|---|
| 40분 | 전공 문항 2–3개 공부 + 말하기 |
| 15분 | 전날 막힌 문항 다시 말하기 |
| 주 2회 +40분 | PT 1회 |

## 2. 2단계: 면접 대상·일정 공지 후 (약 1–2주)

- 60초 답변: 왜 설계(1지망 Solution HW → 설계), 왜 이직(6월 PE 이력 포함)
- 압박 질문 6개(로드맵 2장)
- 심층 모의 2회 (PT 직후 같은 과제로 심층 질문 이어가기 포함)
- A!SK 형식: 1분 준비 + 2분 답변 × 4문항 연속 녹화
- GD 주제 2개 양면 논증 (가볍게)
- 면접 직전 48시간: 새 개념 금지, 막혔던 질문과 경험 숫자만 복습
